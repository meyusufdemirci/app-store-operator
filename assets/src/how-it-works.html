Step 01

Add the server

One command in your terminal. Claude Code registers the server for you.

$ claude mcp add \ --transport stdio \ app-store-operator -- npx -y \ app-store-operator@latest

Ask Claude

A plain-language prompt. No flags, no configuration, no API keys.

“Research rivals for ‘meditation’ in the US App Store.”
